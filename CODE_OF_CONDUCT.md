# 🌸 Code of Conduct

## The short version

**Be kind. Be patient. Be cool.**

We're all here to build something awesome. Let's not make it weird.

---

## The longer version

### ✅ We encourage

- Helping newcomers get started
- Explaining things without condescension
- Respecting different skill levels
- Giving constructive feedback
- Admitting when you don't know something
- Asking questions
- Celebrating others' contributions
- Using emojis freely `(●'◡'●)`

### ❌ We do not tolerate

- Harassment of any kind
- Discriminatory language (race, gender, sexuality, religion, ability, etc.)
- Personal attacks
- Trolling or bad-faith arguments
- Doxxing
- Spam or self-promotion without context
- Being a jerk, even "as a joke"

---

## Scope

This applies to:
- Issues
- Pull requests
- Discussions
- Commit messages
- Anything else attached to this project

---

## Enforcement

If you experience or witness unacceptable behavior:

1. **Report it** by opening a private issue or contacting a maintainer
2. We'll **investigate** calmly and fairly
3. We'll **act** — warning, temporary ban, or permanent ban depending on severity

You don't need proof "beyond a reasonable doubt." If it felt wrong, tell us.

---

## The spirit of the rule

> Treat others the way you'd want to be treated if *you* were the newbie asking a "dumb" question at 2 AM.  
> Because you were, once. We all were.
